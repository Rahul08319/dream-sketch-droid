## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or bun

### 1. Clone the Repository
```bash
git clone https://github.com/Rahul08319/dream-sketch-droid.git
cd dream-sketch-droid
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Environment Setup
Create a `.env` file in the root directory:
```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=your-supabase-publishable-key
```

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser to view the Apple-grade studio.

### 5. Build for Production
```bash
npm run build
```

## 📱 Mobile App (iOS & Android)

Dream Sketch Droid is fully configured for native mobile platforms via Capacitor:

```bash
# Sync web build to native shells
npm run build
npx cap sync

# Open in Xcode (macOS)
npx cap open ios

# Open in Android Studio
npx cap open android
```

## ♾️ Evergreen Automation

This repository includes an automated recurring workflow located at [`.github/workflows/evergreen.yml`](.github/workflows/evergreen.yml).

- **Scheduled Verification**: Automatically triggers monthly via GitHub Actions cron to test dependencies, verify TypeScript builds, and record active health telemetry.
- **Dynamic Year Tracking**: JavaScript runtime computes dynamic calendar years (`2024–present`) across footers, metadata tags, and copyright displays.
- **Zero Drift**: Ensures the project remains active, operational, and green for years to come without requiring manual maintenance.
